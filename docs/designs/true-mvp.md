## Vision

### 10x Check
The 10x version is "AI content strategist that thinks about your business while you sleep." Instead of a reactive content generator, Juno proactively surfaces content plans based on what's trending, what the coach hasn't posted about, and what performs best. Content creation happens in the flow of conversation (coach mentions a client win casually -> Juno offers to turn it into a post). Multi-format output per idea. Performance learning loop builds a "taste model" alongside the voice model.

### Platonic Ideal
The coach opens Juno Monday morning. Without asking, Juno shows a pre-built content plan tied to their business goals, recent client wins mentioned in chat, and audience engagement patterns. Coach taps through, makes one small edit, Juno learns the correction permanently. Every interaction compounds into a deeper understanding of the coach's voice and business. The feeling: "This thing actually knows me."

## Additional Decisions from Review

### Architecture
- Chat schema includes `channel` column from day one (future-proofs for WhatsApp)
- Single Claude API call for multi-format on individual posts; batch generates primary format only

### Security
- Prompt injection protection: wrap user-provided brand profile fields in XML delimiters
- XSS prevention: never use dangerouslySetInnerHTML for AI-generated content
- Per-coach daily generation cap (50/day for beta)

### Design
- Mobile-first UI (coaches use phones between client sessions)
- Anti-slop system prompt library (banned AI phrases, required authenticity markers)
- Navigation: Bottom tab bar (mobile) / sidebar (desktop). 3 tabs: Chat, Drafts, Settings. Admin hidden for founder only.
- Chat is the home screen. No separate dashboard. Open Juno = open conversation.
- Chat style: iMessage/WhatsApp conversational. Coach bubbles right (green-50), Juno bubbles left (gray-100). Content output appears as inline cards.
- Framework picker: Bottom sheet overlay with framework cards. Mobile-native slide-up pattern.
- Batch output: Vertical timeline with day labels + content type badges. Collapsible cards.
- Juno avatar: Green circle with "J" in white.
- IG mockup preview: Pixel-accurate Instagram post frame (profile pic circle, username, caption, like/comment/share icons, hashtags in lighter color).
- Quick actions: Pill-shaped buttons, horizontally scrollable, with emoji icons. Positioned above chat input.
- Refinement buttons: Toolbar below content output. [Shorter] [Longer] [Casual] [Professional] [Spicy].
- Hashtag toggles: Chip/pill components below content. Toggle on/off.
- Copy toast: "Copied!" notification, auto-dismiss after 2s, bottom-center.
- Dark mode: Deferred to post-MVP.

### Design System (baseline)
- Colors: green-600 primary, gray-50 surface, gray-300 borders, gray-900 text, gray-500 secondary text, red-600 error, amber-500 warning
- Typography: Inter (system-ui fallback), text-xl headings, text-base body, text-sm secondary
- Radius: rounded-lg buttons, rounded-xl cards, rounded-2xl chat bubbles
- Shadows: shadow-sm cards, shadow-lg modals
- Touch targets: 44x44px minimum

### Responsive Breakpoints
- Mobile (<640px): Bottom tab bar, full-width chat, horizontal scroll refinement buttons, bottom sheet framework picker
- Tablet (640-1024px): Same as mobile with more padding, centered IG preview
- Desktop (>1024px): Left sidebar nav, max-w-2xl chat, 3-column framework picker overlay

### Accessibility
- Chat input: Enter=send, Shift+Enter=newline, role="textbox"
- Message list: role="log", aria-live="polite"
- All buttons: keyboard navigable, aria-label with full action description
- Hashtag toggles: role="checkbox", aria-checked
- Format tabs: role="tablist", arrow key navigation
- Color contrast: 4.5:1 minimum (WCAG AA)

### Observability
- Structured logging on all API routes
- Claude API token/cost tracking per generation
- Founder admin page (active coaches, generations today, error rate, avg latency)
- Learning loop metrics surfaced in admin view

### Edge Cases (7 fixes included)
1. Brand profile text fields max length
2. Chat message 4KB size limit
3. Double-send prevention (debounce)
4. Batch generation partial failure handling
5. Clipboard API fallback
6. Long caption truncation in IG preview
7. Refinement button clean replacement
