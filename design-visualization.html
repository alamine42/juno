Dual-Path Scheduling (No Missed Posts)

Two paths ensure posts scheduled minutes ahead are never missed. Coaches CAN schedule for any future date—the 2-hour limit only applies to timer materialization.

Path A: Immediate Timer
Coach approves → Immediately create Inngest timer
Handles posts scheduled minutes ahead
Path B: Sweep Validation
Every 10 min → Check timers exist & correct
Catches DST shifts, missing timers
Coach Approves
→
Immediate Timer
(Path A, if <2hr)
+
Sweep Validates
(Path B, 10min)
→
Post Executes
Timezone Snapshot: Store scheduled_timezone at approval time. If coach travels or updates their profile timezone, already-scheduled posts are unaffected.

Inngest Outage Fallback + Recovery

Scheduling intent persisted at approval time (not just within 2hr window). Recovery queries the full intent table.

scheduled_posts table: { content_id, desired_execution_at, timer_status: pending|dispatched|executed }

Hybrid Search Architecture

Pure vector misses exact matches ("8-week" vs "8 week"). Pure keyword misses semantics ("pricing" vs "cost"). Hybrid combines both via RRF.

Full-Text Search
PostgreSQL ts_rank
search_vector @@ query
+
Vector Search
pgvector cosine
embedding <=> query
→
RRF Fusion
score = Σ 1/(k + rank)
Best of both worlds
keyword_weight
Default: 0.5
Balance keyword vs semantic
rrf_k
Default: 60
Smoothing constant
match_count
Default: 10
Results to return
Query Adaptation: Exact lookups (pricing, names) → keyword_weight 0.7 | Conceptual (ideas, themes) → keyword_weight 0.3 | Mixed → keyword_weight 0.5
